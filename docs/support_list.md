# Supported timm models

Call `list_timm_vit_models()` to get this list programmatically. The models
below were validated with `timm==1.0.27`, `torch==2.8.0+cu128`,
`pretrained=False`, and synthetic DAAM forward/backward smoke tests on
2026-05-27. For billion-parameter variants, the smoke test used fp16 on CUDA;
support means hook compatibility, not a memory guarantee for every machine.
